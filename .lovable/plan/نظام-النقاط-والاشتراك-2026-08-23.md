# نظام النقاط والاشتراك

## الفكرة
كل مستخدم جديد يحصل على **٥ نقاط مجانية** عند التسجيل. كل منصة في عملية التوليد = نقطة واحدة (٣ منصات = ٣ نقاط). عند نفاد النقاط يتوقّف التوليد ويُوجَّه المستخدم لصفحة الاشتراك.

النموذج الأول فقط (**Gemini 2.5 Flash Lite**) مفتوح للجميع ويعمل بالنقاط المجانية. باقي النماذج مقفلة بقفل 👑 ولا تعمل إلا لمشترك فعّال.

الاشتراك = **باقة نقاط شهرية** (مثلاً ٥٠٠ نقطة/شهر) تتجدد تلقائيًا في تاريخ التجديد + فتح كل النماذج.

الدفع الآن **تفعيل يدوي**: روابط LemonSqueezy تبقى كما هي، وأنا أضيف واجهة إدارية بسيطة (دور admin) لتفعيل اشتراك أي مستخدم يدويًا، على أن نربط webhook تلقائي لاحقًا.

## قاعدة البيانات
جدول `user_credits` جديد لكل مستخدم:
- `user_id`, `balance` (افتراضي ٥), `plan` (`free` / `pro`), `monthly_grant`, `renews_at`, `updated_at`
- يُنشأ تلقائيًا مع الحساب عبر تعديل trigger `handle_new_user`
- RLS: المستخدم يقرأ سجله فقط ولا يستطيع تعديله إطلاقًا (الخصم يتم على الخادم)

جدول `credit_transactions` لسجل الحركات (خصم توليد / منح اشتراك / تجديد شهري) — قراءة ذاتية فقط.

جدول `user_roles` + enum `app_role` + دالة `has_role` لتحديد الأدمن (مطلوب أمنيًا، لا يُخزَّن الدور في profiles).

## منطق الخادم (Edge Function)
`generate-content` يصبح مصادقًا:
1. يتحقق من JWT المستخدم ويرفض الطلب بدون تسجيل دخول.
2. يقرأ رصيد المستخدم بصلاحية service_role.
3. يتحقق أن النموذج المطلوب مسموح: `gemini-2.5-flash-lite` للجميع، الباقي لخطة `pro` نشطة فقط — وإلا خطأ عربي واضح مع كود `MODEL_LOCKED`.
4. يتحقق أن الرصيد ≥ عدد المنصات، وإلا خطأ `NO_CREDITS`.
5. يخصم النقاط ذريًا (دالة `consume_credits` في الداتابيس) ثم ينفّذ التوليد، ويعيد النقاط في حال فشل الاستدعاء.
6. يعيد الرصيد الجديد مع الرد.

دالة `renew_credits` تُجدّد الرصيد الشهري عند أول استخدام بعد `renews_at`.

Edge Function ثانية `admin-grant-subscription`: يستدعيها الأدمن فقط لتفعيل اشتراك (تحديد الخطة، عدد النقاط، تاريخ التجديد).

## الواجهة
- **الصفحة الرئيسية**: شارة رصيد النقاط أعلى الصفحة (مثال: «٥ نقاط ⚡») تتحدث بعد كل توليد، وتصبح برتقالية عند ≤ ١.
- **محدد النموذج**: النماذج المقفلة تظهر بأيقونة قفل وشارة Pro، والضغط عليها يفتح صفحة `/premium` بدل اختيارها.
- **زر التوليد**: يعرض تكلفة العملية («توليد — ٣ نقاط»)، ويوجّه إلى `/premium` عند عدم كفاية الرصيد.
- **رسائل الخطأ**: توضّح السبب (رصيد غير كافٍ / نموذج يتطلب اشتراك) مع زر «ترقية».
- **صفحة Premium**: تحديث النصوص لتعكس نظام النقاط (٥ نقاط مجانية عند التسجيل، ٥٠٠ نقطة شهريًا للمشترك، كل النماذج مفتوحة) مع عرض الرصيد والخطة الحالية.
- **صفحة الإعدادات**: قسم يعرض الخطة، الرصيد، وتاريخ التجديد.
- **صفحة `/admin`** محمية بدور admin: بحث بالبريد وتفعيل/إلغاء اشتراك يدويًا.
- استبدال `FreeTierPill` بشارة نقاط حقيقية بدل الحالة الوهمية الحالية.

## تفاصيل تقنية
- `getFreeTierStatus` الحالية تعيد `Infinity` — تُستبدل بخدمة `creditsService.js` تقرأ من `user_credits` عبر Supabase.
- كل التحقق من الرصيد والنموذج يتم على الخادم؛ فحوصات الواجهة للعرض فقط.
- الخصم يتم داخل دالة SQL بـ `security definer` لضمان الذرّية ومنع التلاعب.

## ما تحتاج تأكيده لاحقًا
- عدد نقاط الباقة الشهرية (سأستخدم ٥٠٠ افتراضيًا) وأسعار الخطط الحالية.
- بريدك الإلكتروني لتعيينك كأدمن.
